# Publications Google Business — articles de fin d'année

À publier dans la fiche : **Ajouter une mise à jour** (ou « Nouveautés »). Google ne permet pas de programmer une
publication : postez-la **le jour de la mise en ligne de l'article** (sinon le lien mène à une page introuvable).

Règles à respecter pour que Google accepte la publication :
- pas de numéro de téléphone dans le texte (Google refuse souvent ces publications) ;
- le lien se met dans le **bouton**, pas dans le texte ;
- une seule image, celle de ce dossier (1200 × 900).

Visuels régénérables : `CHROMIUM_PATH=… node scripts/gbp-images.mjs --publications`.
